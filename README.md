# KENAME Sport website starter

This is a fresh, responsive static HTML/CSS/JavaScript website based on the approved KENAME Sport website brief.

## Preview locally
Open \`index.html\` in a browser. For best results, use a simple local server (for example, VS Code Live Server).

## Deploy
This branch contains the website at the repository root for GitHub Pages.

## Temporary image and content placeholders
The current preview uses free-to-use Pexels women's-football photographs as remote temporary placeholders, not KENAME event photographs. Replace them in \`assets/styles.css\` with approved KENAME photography before launch. The partner logos, WFMS artwork and header/footer logo mark are clearly marked temporary placeholders.

Review all placeholder copy before launch, especially the founder biography, Behind The Name, news features, video content, Privacy Policy and Terms. Replace social links in \`assets/site.js\` with official KENAME accounts. The contact form currently uses \`mailto:hello@kenamesport.com\`, not a server-side form. Verify the legal display name, trip dates, descriptions, partner permissions and event references before launch.

No Stripe, shopping cart, checkout or payment processing is included.
